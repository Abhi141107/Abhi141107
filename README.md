## ✦ About

I build dashboards, automate reporting and analyze business data. Over five years at Deloitte, PhonePe and CloudSphere, I've worked with SQL, Python and Power BI to track KPIs, investigate anomalies and deliver insights across consulting, digital payments and IT services.

## ✦ Selected work

| Project | What it does | Impact | Stack |
|---------|-------------|--------|-------|
| **p2pexceptions** | Classifies each failed three-way match into a MECE cause taxonomy validated against hand labels | Cost-weighted Pareto | Python, SQL, PostgreSQL, dbt, pytest, Streamlit |
| **costtoserve** | Activity-based cost-to-serve model that flags customers whose profitability sign flips depending on which allocation driver is used | Reveals hidden unprofitable accounts | Python, SQL, PostgreSQL, dbt, PostGIS, pytest |
| **cannibal** | Search cannibalisation detection that tests page pairs with multiple-testing correction | Output is a short list of real competing pairs instead of hundreds of noisy ones | Python, chi-square tests, Bonferroni, Benjamini-Hochberg |
| **quantfrontier** | Quantisation quality/latency frontier measured on downstream tasks and output divergence | Using real integer quantisation on a small MLP and a seeded simulated backend | Python, DuckDB, pytest |
| **nyc-taxi-data-lake-gcp** | Processes NYC TLC Trip Record Dataset (50M+ rows/month) with Dataproc + PySpark | Writes optimized Parquet to GCS with Hive-style partitioning, serves via BigQuery external tables, and transforms with dbt | Python, HTML, HCL, Shell |
| **sigmaforge** | Sigma detection-rule compiler that parses rules into typed expression tree | Renders Splunk SPL, Elastic EQL, Microsoft KQL and SQLite SQL, checked by property-based differential tests | Python |
